# PressCost APK (Print Zone)

1. Create a new GitHub repository and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab -> **Build Android APK** -> wait ~5 minutes for the green tick
   (or press **Run workflow** to start it manually).
3. Open the finished run -> **Artifacts** -> download **PressCost-APK** (zip) -> unzip -> install `app-debug.apk` on your phone
   (allow "Install unknown apps" when asked).

To change the app later: replace `www/index.html` and commit. A new APK is built automatically.
